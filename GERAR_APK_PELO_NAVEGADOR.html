⚠️ Por que o link do WhatsApp não abriu no celular?
O link deste painel de criação é um link privado de teste do Google. Ele só abre no computador do administrador conectado à conta. No celular de outras pessoas, o Google bloqueia o acesso por segurança.

Para enviar por WhatsApp para clientes e motoristas, o sistema precisa estar publicado em um link público gratuito (veja abaixo).
Para Computador / Notebook
💻 No Computador do Cliente (100% Offline)

Basta enviar a pasta do projeto para o cliente e pedir para ele dar dois cliques no arquivo ABRIR_SISTEMA_OFFLINE.bat. Ele abre o sistema na hora, em tela cheia, sem precisar de internet e sem instalar nada!

Para Gerar o .APK Nativo
📦 Projeto Android já Pronto na sua Pasta (Pasta "android")

Já criamos a pasta android dentro do seu projeto com todo o código compilado embutido. Quem tiver o programa gratuito Android Studio instalado no computador, basta abrir a pasta "android" e clicar no menu Build > Build APK. O arquivo .apk sai pronto em 1 minuto!

Para WhatsApp em Qualquer Celular
🌐 Como gerar um Link Público Gratuito para WhatsApp

Para o motorista e o cliente poderem abrir e instalar o aplicativo direto pelo WhatsApp, você pode subir a pasta dist em um site de hospedagem gratuita como Netlify (leva 30 segundos: só arrastar a pasta dist para o site netlify.com/drop) ou Vercel. Ele gera um link como osnirturismo.netlify.app que abre em qualquer celular e qualquer WhatsApp do mundo!
