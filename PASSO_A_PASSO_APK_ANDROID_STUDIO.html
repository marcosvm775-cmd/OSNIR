📱 Gerar o APK no Android Studio

O Android Studio tem muitas telas, mas você só precisa de 3 cliques!

1 Abrir a pasta do seu aplicativo
No Android Studio, clique em File ➔ Open... (ou clique no botão Open da tela inicial).
Selecione a pasta chamada android que está dentro da pasta do seu projeto.
(Aguarde 1 minuto enquanto ele carrega os arquivos – aparece uma barra azul no rodapé).
2 Clicar para gerar o APK
No menu superior do Android Studio (na barra de cima da tela), clique na seguinte sequência:
Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)

Só isso! O computador vai começar a criar o seu arquivo APK.
3 Pegar o arquivo APK pronto
Aguarde cerca de 1 a 2 minutos. No cantinho inferior direito da tela do Android Studio, vai aparecer um balão azul avisando:
🎉 APK(s) generated successfully for 1 module:
Clique na palavrinha azul sublinhada chamada locate

Ao clicar em locate, o Windows vai abrir a pasta direto com o arquivo app-debug.apk prontinho!

Basta renomear para OSNIR_TURISMO.apk e enviar para o celular pelo WhatsApp ou Pen Drive!
