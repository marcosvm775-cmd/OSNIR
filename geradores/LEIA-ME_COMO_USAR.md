# 📁 PASTA DE GERADORES & FERRAMENTAS DO ADMINISTRADOR
### Sistema OSNIR TURISMO

Esta pasta contém todas as ferramentas exclusivas do proprietário/administrador do sistema.
**Não envie esta pasta para os clientes.**

---

### 🛠️ O que há nesta pasta:

1. **`gerador-chaves-osnir.html`**
   * Ferramenta para emissão de chaves oficiais do sistema (Mensal, Semestral, Anual e Vitalícia).
   * Funciona direto no seu navegador com dois cliques (no PC ou no celular).
   * Possui botão rápido para copiar mensagem formatada pronta para enviar no WhatsApp do cliente com seu telefone de suporte: `(37) 9 9124-3101`.

2. **`GERAR_INSTALADOR_FACIL.bat`**
   * Cria com 1 clique o instalador executável oficial do Windows (`.exe`) com assistente de instalação NSIS e atalhos automáticos.
   * O instalador final pronto fica na pasta: `INSTALADOR_FINAL_PARA_O_CLIENTE\`.

3. **`GERAR_APK_CELULAR.bat`**
   * Cria o pacote de instalação do aplicativo para celular Android (`.apk`).
   * O arquivo pronto fica na pasta: `SEU_APK_AQUI\OSNIR_TURISMO.apk`.

4. **`INSTALAR_JAVA_17_AUTOMATICO.bat`**
   * Utilitário que baixa e instala o Java 17 LTS oficial caso o computador não o possua para compilar o APK Android.

---

### 📱 Como funciona no iPhone (iOS):
* No iPhone não se usa arquivo `.apk` nem `.exe`. A Apple utiliza o padrão **PWA (Progressive Web App)**.
* Ao abrir o sistema no navegador **Safari** do iPhone ou iPad, basta tocar no ícone de **Compartilhar** (quadrado com seta para cima) e selecionar **"Adicionar à Tela de Início"**.
* O aplicativo fica salvo na memória interna do iPhone com o ícone oficial, funcionando em tela cheia e offline!
