🔍 Por que está estranho e onde estão as opções?

Veja em qual dessas 4 situações a sua tela do Android Studio se encaixa:

1️⃣ Sua tela é cinza e diz "Welcome to Android Studio"?
Nessa tela inicial NÃO EXISTE o menu "Build" ainda! Isso é normal!
Você precisa abrir a pasta do projeto primeiro:

👉 Clique no botão "Open" (ícone de pasta).
👉 Navegue até a pasta do seu projeto e selecione apenas a pasta chamada "android" (ela tem o ícone de um robozinho verde).
👉 Clique em OK.
2️⃣ O Android Studio escondeu a barra de menus no botão [ ☰ ]
Nas versões novas do Android Studio, a palavra Build fica escondida dentro de um botão de 3 risquinhos horizontais (☰) lá no cantinho superior esquerdo da janela!

👉 Olhe bem no cantinho superior esquerdo da tela do Android Studio.
👉 Clique no ícone de 3 risquinhos ☰.
👉 O menu vai se abrir! Aí sim você verá: Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s).
3️⃣ A palavra "Build APK" não aparece dentro de Build?
Se você abriu a pasta mãe osnir-turismo, o Android Studio não sabe que é um aplicativo Android.
Como corrigir:
👉 No Android Studio, vá em File ➔ Open.
👉 Escolha diretamente a subpasta "android" (ex: C:\...\osnir-turismo\android).
👉 Ele vai reconhecer na hora como aplicativo móvel!
4️⃣ Tem uma barra azul ou texto se mexendo lá embaixo?
No rodapé (na parte de baixo da tela), pode estar escrito "Gradle: Syncing..." ou "Indexing...".
Enquanto essa barrinha estiver trabalhando, o Android Studio bloqueia o menu Build.
👉 Basta esperar 1 a 2 minutos até a barra sumir e aparecer a mensagem verde "Sync successful".
